15:T3051,<h2 id="overview">Overview</h2>
<p>Veezoo supports the <code>html</code> property for various knowledge graph concepts, including:</p>
<ul>
<li>Classes</li>
<li>Numbers</li>
<li>Dates</li>
<li>Booleans</li>
<li>Strings</li>
<li>Measures</li>
<li>Functions</li>
<li>Units</li>
</ul>
<p>The <code>html</code> property allows embedding custom HTML using the <a href="https://shopify.github.io/liquid/">Liquid templating language</a>, making it easy to format values dynamically.</p>
<h3 id="available-constants">Available Constants</h3>
<p>Within the <code>html</code> property, you can use the following constants:</p>
<ul>
<li><code>value</code>: The raw value.</li>
<li><code>formatted_value</code>: The value formatted using <code>format_number</code>, ensuring proper number formatting.</li>
<li><code>min_value</code> / <code>max_value</code>: (For numbers only) The minimum and maximum values in the corresponding column.</li>
</ul>
<h3 id="available-filters">Available Filters</h3>
<p>The following filters are available in Liquid expressions and have been implemented to provide localization-aware formatting:</p>
<h4 id="format_number"><code>format_number</code></h4>
<p>Formats a number using the user's number format preferences. You can optionally override the locale and other formatting options using named arguments:</p>
<figure class="docs-code"><pre class="shiki github-light" style="background-color:#fff;color:#24292e" tabindex="0"><code><span class="line"><span style="color:#24292E">{{ value | format_number: locale: 'de-DE', style: 'currency', currency: 'EUR' }}</span></span></code></pre></figure>
<p>Like <code>format_number_compact</code>, this filter supports any options defined in the <a href="https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/NumberFormat/NumberFormat"><code>Intl.NumberFormat</code></a> constructor. These include:</p>
<ul>
<li><code>style</code>: <code>'decimal'</code>, <code>'currency'</code>, <code>'percent'</code>, <code>'unit'</code></li>
<li><code>currency</code>: e.g., <code>'USD'</code>, <code>'EUR'</code></li>
<li><code>minimumFractionDigits</code>, <code>maximumFractionDigits</code></li>
<li><code>notation</code>: <code>'standard'</code>, <code>'scientific'</code>, <code>'engineering'</code>, etc.</li>
</ul>
<p>Example:</p>
<figure class="docs-code"><pre class="shiki github-light" style="background-color:#fff;color:#24292e" tabindex="0"><code><span class="line"><span style="color:#24292E">{{ value | format_number: style: 'unit', unit: 'kilobyte', unitDisplay: 'narrow' }}</span></span></code></pre></figure>
<p>This will display a number like <code>1,024 KB</code>.</p>
<h4 id="format_number_compact"><code>format_number_compact</code></h4>
<p>Formats a number using compact notation (e.g., <code>K</code>, <code>M</code>, etc.). Defaults to <code>'en-US'</code> locale unless overridden:</p>
<figure class="docs-code"><pre class="shiki github-light" style="background-color:#fff;color:#24292e" tabindex="0"><code><span class="line"><span style="color:#24292E">{{ value | format_number_compact }}</span></span>
<span class="line"><span style="color:#24292E">{{ value | format_number_compact: locale: 'de-DE' }}</span></span></code></pre></figure>
<p>You can also pass additional options supported by the <a href="https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/NumberFormat/NumberFormat"><code>Intl.NumberFormat</code></a> constructor, such as:</p>
<figure class="docs-code"><pre class="shiki github-light" style="background-color:#fff;color:#24292e" tabindex="0"><code><span class="line"><span style="color:#24292E">{{ value | format_number_compact: locale: 'en-US', maximumFractionDigits: 1 }}</span></span></code></pre></figure>
<p>This gives you control over rounding, currency display, unit style, and other formatting aspects.</p>
<h4 id="format_date"><code>format_date</code></h4>
<p>Formats a date using <a href="https://date-fns.org/"><code>date-fns</code></a> and supports format strings and localization:</p>
<figure class="docs-code"><pre class="shiki github-light" style="background-color:#fff;color:#24292e" tabindex="0"><code><span class="line"><span style="color:#24292E">{{ value | format_date: 'EEEE, MMMM d, yyyy', locale: 'fr' }}</span></span></code></pre></figure>
<ul>
<li>The first argument is the date format string, following the <a href="https://date-fns.org/v2.30.0/docs/format"><code>date-fns/format</code></a> syntax.</li>
<li>You can pass a <code>locale</code> option to customize formatting to different languages. The locale uses the user's language by default but can be overridden.</li>
<li>Other options such as <code>weekStartsOn</code> or <code>firstWeekContainsDate</code> can be passed too.</li>
</ul>
<p><strong>Examples:</strong></p>
<figure class="docs-code"><pre class="shiki github-light" style="background-color:#fff;color:#24292e" tabindex="0"><code><span class="line"><span style="color:#24292E">{{ value | format_date: 'yyyy-MM-dd' }} → 2024-06-15</span></span>
<span class="line"><span style="color:#24292E">{{ value | format_date: 'PPPP', locale: 'it' }} → sabato 15 giugno 2024</span></span>
<span class="line"><span style="color:#24292E">{{ value | format_date: 'MMM do, yyyy' }} → Jun 15th, 2024</span></span></code></pre></figure>
<p>See the full list of tokens at the <a href="https://date-fns.org/v2.30.0/docs/format">date-fns documentation</a>.</p>
<h2 id="examples">Examples</h2>
<h3 id="formatting-a-number-with-thousand-separators">Formatting a Number with Thousand Separators</h3>
<figure class="docs-code"><pre class="shiki github-light" style="background-color:#fff;color:#24292e" tabindex="0"><code><span class="line"><span style="color:#24292E">{{ formatted_value }}</span></span></code></pre></figure>
<p>If <code>value</code> is <code>1234567.89</code>, this will display as <code>1,234,567.89</code> based on user locale settings.</p>
<h3 id="displaying-conditional-icons-for-values">Displaying Conditional Icons for Values</h3>
<figure class="docs-code"><pre class="shiki github-light" style="background-color:#fff;color:#24292e" tabindex="0"><code><span class="line"><span style="color:#24292E">{% if value > 1000000 %}</span></span>
<span class="line"><span style="color:#24292E">    &#x3C;</span><span style="color:#22863A">span</span><span style="color:#24292E">>🔥 {{ formatted_value }}&#x3C;/</span><span style="color:#22863A">span</span><span style="color:#24292E">></span></span>
<span class="line"><span style="color:#24292E">{% else %}</span></span>
<span class="line"><span style="color:#24292E">    &#x3C;</span><span style="color:#22863A">span</span><span style="color:#24292E">>💰 {{ formatted_value }}&#x3C;/</span><span style="color:#22863A">span</span><span style="color:#24292E">></span></span>
<span class="line"><span style="color:#24292E">{% endif %}</span></span></code></pre></figure>
<p>If <code>value</code> is <code>1500000</code>, this will display: <strong>🔥 1,500,000</strong>.
If <code>value</code> is <code>50000</code>, this will display: <strong>💰 50,000</strong>.</p>
<h3 id="applying-a-compact-number-format">Applying a Compact Number Format</h3>
<figure class="docs-code"><pre class="shiki github-light" style="background-color:#fff;color:#24292e" tabindex="0"><code><span class="line"><span style="color:#24292E">{{ value | format_number_compact }}</span></span></code></pre></figure>
<p>If <code>value</code> is <code>1500000</code>, this will display as <code>1.5M</code> using the default <code>en-US</code> locale.</p>
<h3 id="displaying-the-weekday-and-date">Displaying the Weekday and Date</h3>
<figure class="docs-code"><pre class="shiki github-light" style="background-color:#fff;color:#24292e" tabindex="0"><code><span class="line"><span style="color:#24292E">{{ value | format_date: 'EEEE, MMMM d, yyyy' }}</span></span></code></pre></figure>
<p>If <code>value</code> is <code>2024-06-15</code>, this will display <strong>Saturday, June 15, 2024</strong>.</p>
<h3 id="adding-custom-html-for-a-url-field">Adding Custom HTML for a URL Field</h3>
<figure class="docs-code"><pre class="shiki github-light" style="background-color:#fff;color:#24292e" tabindex="0"><code><span class="line"><span style="color:#24292E">&#x3C;</span><span style="color:#22863A">a</span><span style="color:#6F42C1"> href</span><span style="color:#24292E">=</span><span style="color:#032F62">"{{ value }}"</span><span style="color:#6F42C1"> target</span><span style="color:#24292E">=</span><span style="color:#032F62">"_blank"</span><span style="color:#24292E">>Open Link&#x3C;/</span><span style="color:#22863A">a</span><span style="color:#24292E">></span></span></code></pre></figure>
<p>If <code>value</code> is <code>https://example.com</code>, this will create a clickable hyperlink.</p>
<h3 id="showing-a-conditional-badge-for-high-values">Showing a Conditional Badge for High Values</h3>

<h2 id="considerations">Considerations</h2>
<ul>
<li>Ensure all HTML is properly sanitized to prevent security issues.</li>
<li>Use <code>format_number</code>, <code>format_number_compact</code>, and <code>format_date</code> for proper localization.</li>
<li>The <code>html</code> property is optional, and if not defined, the default formatted value is used.</li>
</ul>
