15:T23ee,<h2 id="definition">Definition</h2>
<p>A numeric attribute is used whenever you have a column or SQL expression that returns a number, e.g. an integer or a decimal number.</p>
<h2 id="usage">Usage</h2>
<p>File: <em>hitchhiker/knowledge-base/classes/Order.vkl</em></p>
<figure class="docs-code"><pre class="shiki github-light" style="background-color:#fff;color:#24292e" tabindex="0"><code><span class="line"><span style="color:#D73A49">import</span><span style="color:#24292E"> db.postgres.movie_db.public.ORDERS</span></span>
<span class="line"></span>
<span class="line"><span style="color:#24292E">kb {</span></span>
<span class="line"></span>
<span class="line"><span style="color:#24292E">    class Order {</span></span>
<span class="line"></span>
<span class="line"><span style="color:#24292E">        ...</span></span>
<span class="line"></span>
<span class="line"><span style="color:#24292E">        number Order_Total {</span></span>
<span class="line"><span style="color:#24292E">            name.en: </span><span style="color:#032F62">"Order Total"</span></span>
<span class="line"><span style="color:#24292E">            synonym.en: [</span><span style="color:#032F62">"Price"</span><span style="color:#24292E">, </span><span style="color:#032F62">"Revenue"</span><span style="color:#24292E">, </span><span style="color:#032F62">"Amount"</span><span style="color:#24292E">]</span></span>
<span class="line"></span>
<span class="line"><span style="color:#24292E">            unit: onto.Currency.USD</span></span>
<span class="line"></span>
<span class="line"><span style="color:#24292E">            sql: </span><span style="color:#032F62">"${ORDERS.order_total}"</span></span>
<span class="line"><span style="color:#24292E">        }    </span></span>
<span class="line"><span style="color:#24292E">    }</span></span>
<span class="line"><span style="color:#24292E">}</span></span></code></pre></figure>
<p>Notice the <a href="..">unit</a> parameter, which allows Veezoo to display the value in the appropriate format to the user.</p>
<p>As with the other kinds of attributes, you can also apply any kind of compatible SQL transformation inside <code>sql</code>.</p>
<p>Let's say instead that your attribute <code>kb.Order.Order_Total</code> contains values in different currencies (USD, CHF, EUR), specified in the column <code>ORDERS.currency</code> (imported as class <code>kb.Order.Currency</code>).
Now, summing these values up wouldn't make any sense. So we define a new attribute <code>Order_Total_EUR</code>, which converts the values according to a fixed exchange rate.</p>
<figure class="docs-code"><pre class="shiki github-light" style="background-color:#fff;color:#24292e" tabindex="0"><code><span class="line"><span style="color:#D73A49">import</span><span style="color:#24292E"> db.postgres.movie_db.public.ORDERS</span></span>
<span class="line"></span>
<span class="line"><span style="color:#24292E">kb {</span></span>
<span class="line"></span>
<span class="line"><span style="color:#24292E">    class Order {</span></span>
<span class="line"></span>
<span class="line"><span style="color:#24292E">        ...</span></span>
<span class="line"></span>
<span class="line"><span style="color:#24292E">        number Order_Total_EUR {</span></span>
<span class="line"><span style="color:#24292E">            name.en: </span><span style="color:#032F62">"Order Total (EUR)"</span></span>
<span class="line"><span style="color:#24292E">            synonym.en: [</span><span style="color:#032F62">"Price"</span><span style="color:#24292E">, </span><span style="color:#032F62">"Revenue"</span><span style="color:#24292E">, </span><span style="color:#032F62">"Order Total"</span><span style="color:#24292E">]</span></span>
<span class="line"></span>
<span class="line"><span style="color:#24292E">            unit: onto.Currency.EUR</span></span>
<span class="line"></span>
<span class="line"><span style="color:#24292E">            sql:</span></span>
<span class="line"><span style="color:#032F62">                ""</span><span style="color:#24292E">"</span></span>
<span class="line"><span style="color:#24292E">                CASE </span><span style="color:#22863A">${</span><span style="color:#24292E">kb.Order.Currency</span><span style="color:#22863A">}</span></span>
<span class="line"><span style="color:#24292E">                   WHEN </span><span style="color:#032F62">'USD'</span><span style="color:#24292E"> THEN </span><span style="color:#22863A">${</span><span style="color:#24292E">kb.Order.Order_Total</span><span style="color:#22863A">}</span><span style="color:#005CC5"> *</span><span style="color:#24292E"> 0.83</span></span>
<span class="line"><span style="color:#24292E">                   WHEN </span><span style="color:#032F62">'CHF'</span><span style="color:#24292E"> THEN </span><span style="color:#22863A">${</span><span style="color:#24292E">kb.Order.Order_Total</span><span style="color:#22863A">}</span><span style="color:#005CC5"> *</span><span style="color:#24292E"> 0.92</span></span>
<span class="line"><span style="color:#24292E">                   ELSE </span><span style="color:#22863A">${</span><span style="color:#24292E">kb.Order.Order_Total</span><span style="color:#22863A">}</span></span>
<span class="line"><span style="color:#24292E">                END   </span></span>
<span class="line"><span style="color:#032F62">                ""</span><span style="color:#24292E">"</span></span>
<span class="line"></span>
<span class="line"><span style="color:#24292E">        }    </span></span>
<span class="line"><span style="color:#24292E">    }</span></span>
<span class="line"><span style="color:#24292E">}</span></span></code></pre></figure>
<p>Notice here that we have referred inside the curly brackets <code>${...}</code> to a <code>kb</code> concept, instead of a <code>db</code> concept. This allows us to use recursively the definitions in the <code>sql</code> from these <code>kb</code> concepts.</p>
<p>For example, we could now build on top of <code>kb.Order.Order_Total_EUR</code> like this:</p>
<figure class="docs-code"><pre class="shiki github-light" style="background-color:#fff;color:#24292e" tabindex="0"><code><span class="line"><span style="color:#D73A49">import</span><span style="color:#24292E"> db.postgres.movie_db.public.ORDERS</span></span>
<span class="line"></span>
<span class="line"><span style="color:#24292E">kb {</span></span>
<span class="line"></span>
<span class="line"><span style="color:#24292E">    class Order {</span></span>
<span class="line"></span>
<span class="line"><span style="color:#24292E">        ...</span></span>
<span class="line"></span>
<span class="line"><span style="color:#24292E">        boolean Awesome {</span></span>
<span class="line"><span style="color:#24292E">            name.en: </span><span style="color:#032F62">"Awesome"</span></span>
<span class="line"></span>
<span class="line"><span style="color:#24292E">            sql: </span><span style="color:#032F62">"${kb.Order.Order_Total_EUR} > 1000"</span></span>
<span class="line"></span>
<span class="line"><span style="color:#24292E">        }    </span></span>
<span class="line"><span style="color:#24292E">    }</span></span>
<span class="line"><span style="color:#24292E">}</span></span></code></pre></figure>
<p>This is a <a href="/vkl/kb-layer/attribute/types/boolean">boolean</a>, defining "awesome" orders as those with a total order value normalized in Euro above 1000. How awesome is that!</p>
<h3 id="integer">Integer</h3>
<p>You can also be more precise on the type of number and define it as an <code>integer</code>.</p>
<figure class="docs-code"><pre class="shiki github-light" style="background-color:#fff;color:#24292e" tabindex="0"><code><span class="line"><span style="color:#D73A49">import</span><span style="color:#24292E"> db.postgres.movie_db.public.ORDERS</span></span>
<span class="line"></span>
<span class="line"><span style="color:#24292E">kb {</span></span>
<span class="line"></span>

<span class="line"></span>
<span class="line"><span style="color:#24292E">        ...</span></span>
<span class="line"></span>
<span class="line"><span style="color:#24292E">        integer Quantity {</span></span>
<span class="line"><span style="color:#24292E">            name.en: </span><span style="color:#032F62">"Quantity"</span></span>
<span class="line"><span style="color:#24292E">            synonym.en: [</span><span style="color:#032F62">"Qty"</span><span style="color:#24292E">]</span></span>
<span class="line"></span>
<span class="line"><span style="color:#24292E">            sql: </span><span style="color:#032F62">"${ORDERS.quantity}"</span></span>
<span class="line"><span style="color:#24292E">        }    </span></span>
<span class="line"><span style="color:#24292E">    }</span></span>
<span class="line"><span style="color:#24292E">}</span></span></code></pre></figure>
