Share boards with other users

To facilitate re-use, boards can be shared with other users in Veezoo. As we describe below, you can share any board you have created with individual users, groups, or the whole organization, granting either view or edit access.

Sharing a board

To share a board, open the board and click the "Share" button in the footer:

Alternatively, you can select the "Share" item of the three-dot dropdown menu in the sidebar:

This opens a sharing dialog, which looks as follows:

As we discuss next, you can share your board with individual users, groups, or with the whole organization. You can even combine these sharing methods. Creators and Admins have additional options as described below.

Note

For each user or group you share with, you can choose between view and edit access. Users with view access can only see the board, while users with edit access can also modify it. The board's owner always keeps full control over the board and its sharing settings.

Sharing with individual users

To share the board with individual users, use the upper section of the dialog and add as many users as you wish. You can search for individual users by name in the text box.

For example, we can share the given board with an individual colleague as follows:

The sharing becomes effective once you click the "Share" button. That user will then find the shared board "Revenue Overview" in their sidebar:

Sharing with groups

Besides individual users, you can share a board with an entire group of users at once. Groups correspond to discoverable roles defined in Veezoo Admin - for example a department, team, or working group. Search for the group by name in the same text box you use for users and select it from the dropdown.

Everyone in the group gets access to the board, and it appears in their sidebar automatically. As with individual users, you can grant a group either view or edit access.

Note

Only roles that an admin marked as discoverable are available as groups. Creators and Admins can additionally share with any role, as described below.

Sharing with the organization

You can share your board with the whole organization using the "General access" section of the dialog. To this end, use the dropdown menu to change "Restricted" to "Organization", and click the "Share" button to activate the sharing:

Note

Because boards are specific to a knowledge graph, these are only accessible for users with access to the corresponding knowledge graph, even when shared with "everyone in your organization."

Note

Boards shared with the whole organization do not automatically appear in all users' sidebars. Instead, such boards are listed in the Browse Shared Boards window, as we demonstrate below.

When combining organization-wide sharing with user-based sharing, the board will be added to the sidebars of all explicitly listed users.

Stopping or updating a sharing

To stop sharing a board or edit its sharing settings, use the corresponding buttons in the footer of the board:

Alternatively, you can also find these options in the three-dot dropdown menu in the sidebar:

Boards shared with you

Boards that are shared explicitly with your user are added to your sidebar by default. To avoid cluttering everyone's sidebars, this is different for boards shared with the whole organization. In particular, you need to manually subscribe to such boards as we described next.

Tip

If a board was shared with you with view access only, you cannot edit it. Using the "Create Copy" option in the three-dot dropdown menu, you can always create your own copy of a board that is shared with you. This copy is independent and can be edited freely.

Adding a shared board to the sidebar

Using the corresponding icon in the sidebar, you can open the Browse Shared Boards window:

This window lists all boards shared with you, including those shared with your user explicitly and those shared with the whole organization. The window provides sorting and filtering options allowing you to browse effortlessly through the list of available boards. While the list only displays metadata such as the board title or author name, you can hover on a list entry and use the preview button to peek at the board:

In order to add a board of the list to your sidebar, you need to subscribe to it by clicking the corresponding button:

All shared boards you are subscribed to are included in your sidebar.

Removing shared boards from the sidebar

You can use the Browse Shared Boards window to remove shared boards from your sidebar. In particular, click the "Unsubscribe" button for any board you want to remove:

Special features for creators and admins

Creators and Admins are provided additional sharing options.

Sharing with roles

As a Creator or Admin, you can share boards with any role, not only the discoverable ones available as groups to all users. This lets you share analytical insights and dashboards with the right groups of users, enhancing collaboration while ensuring data security.

In particular, you can search for a role name using the text box and select it from the dropdown menu in the upper section of the sharing dialog. For example, we can share the Creator's Board with the Management role as follows:

Note

Boards shared with roles automatically appear in the corresponding users' sidebars.

Adding boards to sidebars by default

When sharing boards with the whole organization, the boards are not included in all users' sidebars by default. However, as a Creator or Admin, you have the option to override this and make sure all users are subscribed to the respective board by default. To this end, simply check the corresponding checkmark:

Note

Users can still manually unsubscribe from the board again.

Defining Boards in VKL

As we describe in more detail here, boards can also be defined as part of the knowledge graph, in VKL. Such VKL boards are shared with the whole organization or a specific set of roles, and appear in the respective users' sidebars by default. In the Browse Shared Boards window, they are listed as being "Defined in Knowledge Graph."

Note

Like for regular boards, users can manually unsubscribe from VKL boards.
